# Certification badges

Used by the "ISO certified" section on every product detail page
(`src/components/products/IsoCertifiedSection.jsx`). Drop the real badge
artwork in using these exact filenames and the fallback tiles disappear
automatically — no code changes needed, same as every other image slot on
this site.

- `iso-9001-badge.png` — ISO 9001 quality management certification mark
- `ce-machine-directive-badge.png` — CE mark / EU Machine Directive
  compliance mark

Recommended: square artwork, at least 300px, transparent background so it
sits cleanly on the white badge tile.
